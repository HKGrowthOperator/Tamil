# Abnahmen

Eine Datei je Abnahme: `<JJJJ-MM-TT>-<tor>.md`, z. B. `2026-11-12-G1.md`. Abnahmen laufen immer über Luis.

```markdown
# Tor G1 – Brief und Referenzen

- Datum: 2026-11-12
- Gezeigt: <Link zum Artifact / zur Seite>, Stand <Commit>
- Urteil (wörtlich, wie von Luis übermittelt): „…“
- Ergebnis: angenommen | angenommen mit Änderungen | abgelehnt
- Änderungswünsche:
  - …
- Nächster Schritt: …
```

| Tor | Was | Danach erlaubt |
|---|---|---|
| G1 | Brief und Referenzen | Richtungsskizzen (`/design-runde`) |
| G2 | eine Richtung | Probeseite (`/design-ausbau`) |
| G3 | Probeseite | Theme und Cockpit (`/design-umsetzung`) |
| G4 | Live-Website mit echten Inhalten | Go-live-Vorbereitung, Merge PR #2 |

Bisher (vor Einführung der Tore, siehe `docs/entscheidungen.md`): Entwurf v3 „Katastrophe“, Community-Magazin
„altbacken“, Gen-Z-Probeseite „generisch“ – alle abgelehnt.
